## Minor finding

`dashboard/components/CaptionVariants.jsx:32` offers “Create a new video from this idea” for every submission error. During an active render, repeating the request correctly says to finish the current video but also offers this recreation link. This can suggest unnecessary recreation for a temporary conflict. Show a link to the active job for that case and reserve recreation for unavailable render data. No implementation changes made.
